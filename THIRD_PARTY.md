# Third-party provenance

- **DeepSeek-V4.1-Flash-1017 (DeepSeek):** MIT. `scripts/download.py` fetches [revision 1bae0e1088993b9b82de08f59de5be5a34e42170](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017/tree/1bae0e1088993b9b82de08f59de5be5a34e42170) and checks every file. No weights are included in this repository, and none are converted: the engine reads the native MXFP4 experts and FP8 dense weights from the downloaded shards.
- **DeepSeek prompt encoding and examples:** MIT, copied unchanged from the same revision. `api/ds41_api/encoding.py`, `encoding_README.md` and `test_encoding.py` with `api/ds41_api/tests/` are the model repo's `encoding/` folder; `api/inference/examples/` is its `inference/examples/`. `tests/test_repository.py` checks them against the revision's git blob hashes. `scripts/prepare_assets.py` imports the downloaded `inference/model.py` and `inference/engram.py` in place to export the RoPE table and the Engram hash tables; it does not copy them.
- **nlohmann/json 3.12.0 (Niels Lohmann):** MIT. Single header, unchanged, in `engine/vendor/` and `components/dense/engram/vendor/`.
- **TileLang 0.1.12 and its bundled CUTLASS 4.1.0:** MIT and BSD-3-Clause. `scripts/build.sh` downloads the PyPI wheel (SHA-256 pinned in `sources.lock.json`) and compiles `components/attn` against its headers. Nothing from it is redistributed here.
- **NVIDIA cuBLAS 13.1.1.3:** NVIDIA's license for the `nvidia-cublas` wheel. `scripts/build.sh` downloads the wheel (SHA-256 pinned) and copies `libcublas.so.13` and `libcublasLt.so.13` into `build/dist/blas`; they are not redistributed here. The CUDA Toolkit 13.4.0 (nvcc, cudart, cuFile) is installed separately under NVIDIA's EULA.
- **Benchmark prompts (`benchmarks/cases`):** token IDs of three prompts written for this project (MIT), one conversation from allenai/WildChat-1M (ODC-By 1.0, [`LICENSES/ODC-By-1.0.txt`](LICENSES/ODC-By-1.0.txt)) and two runs from ProCreations/betterwright-agent-traces (Apache-2.0, [`LICENSES/Apache-2.0.txt`](LICENSES/Apache-2.0.txt)). Sources, changes and attribution: [`benchmarks/cases/NOTICE.md`](benchmarks/cases/NOTICE.md).
- **PyTorch and the other Python packages:** installed from PyPI and the PyTorch index at the versions in `requirements.txt` and `requirements-assets.txt`; each keeps its own license.

Everything else (the ds41d engine, the expert store, the dense, attention, fused-head and DSpark components, the API server and the scripts) was written for this project and is MIT.
